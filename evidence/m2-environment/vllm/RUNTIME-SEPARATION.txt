Decision
--------

Do not merge vLLM 0.30.0 into the M2.6 project Python environment.

The vLLM runtime is treated as an isolated execution environment until
a future dependency convergence exercise proves a shared stack.

Supported future deployment forms:

  dedicated virtual environment
  isolated runtime lock/profile
  containerized vLLM service

This decision protects the previously qualified M2.4, M2.5 and M2.6
dependency baselines.
